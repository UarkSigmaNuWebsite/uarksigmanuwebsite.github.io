# How to Update the Chapter Website

This is the chapter's website. You don't need to know how to code to update it —
you'll use an AI assistant called **Claude Code** to make changes for you, in
plain English. This guide walks you through it.

**Live site:** https://uarksigmanuwebsite.github.io/sigma-nu-gamma-upsilon/

---

## What you need (one-time)
1. **The shared chapter GitHub login** — it's kept with the chapter's Instagram
   and email logins (passed down each year). It is NOT written down in this
   website, on purpose, because this site is public.
2. **A Claude account** with a plan that includes Claude Code (this is a paid
   subscription — check current pricing at claude.ai).
3. **Claude Code installed** on your computer (claude.ai/code has the download
   and setup steps).

> First time is the hardest part. If you get stuck on setup, you can literally
> ask Claude for help: *"Help me install Claude Code and open the Sigma Nu
> website repo from GitHub."* It will walk you through it.

---

## Opening the website to edit it
1. Sign in to Claude Code with your Claude account.
2. Point it at the chapter's repository:
   `github.com/UarkSigmaNuWebsite/sigma-nu-gamma-upsilon`
   (You can tell Claude: *"Clone and open this repo: <the URL above>"*.)
3. That's it — Claude now has the whole website open and knows how it's built
   (there's a `CLAUDE.md` file that briefs it automatically).

---

## Making a change
Just describe what you want in plain English. A few of the most common jobs,
with example wording you can copy:

- **Change an officer:**
  *"On the Contact page, change the Eminent Commander from Karch Gilley to
  [New Name], [City, State]."*

- **Update the Rush Chairmen:**
  *"Update the Rush Chairmen everywhere they appear to: [Name] ([State]),
  [Name] ([State])."*

- **Update the alumni tailgate game:**
  *"On the Alumni page, change the tailgate to Arkansas vs [Opponent] on
  [Date], in [City]."*

- **Add gallery photos:**
  *"Add these photos to the gallery"* — then drop the image files in and tell
  Claude the caption and date for each.

- **Update the donation / Venmo link:**
  *"On the Give page, set the Venmo link to [your Venmo URL]."*

After Claude makes the change, tell it: **"Commit and push it."** That publishes
it to the live site.

---

## The golden rules
1. **Describe what you want plainly** — you don't need the right technical words.
2. **Let Claude make and push the change** — don't hand-edit files unless you
   know what you're doing.
3. **Always check the live site afterward.** Wait about a minute after pushing,
   then open the live link on your phone and computer to confirm it looks right.
4. **If something looks broken,** tell Claude: *"That broke the page, please
   undo the last change."* Every change is saved in history, so nothing is ever
   truly lost.

---

## Handing it down
When you pass the chapter down, pass along:
- the shared **chapter GitHub login** (with the Instagram/email logins), and
- a pointer to **this file.**

That's the whole handoff. Whoever holds the chapter login can update the site.
